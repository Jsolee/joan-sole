# joan-sole.com

Personal portfolio of Joan Solé, fullstack developer in Barcelona.

Next.js 16 (App Router, fully static), Tailwind v4, GSAP (ScrollTrigger, SplitText), Lenis, and a three.js hero rendered through a custom ordered-dithering pass.

```bash
npm install
npm run dev
```

- Copy and project data: `src/content.ts`
- Scroll and intro choreography: `src/components/Motion.tsx`
- WebGL hero: `src/components/HeroCanvas.tsx`
